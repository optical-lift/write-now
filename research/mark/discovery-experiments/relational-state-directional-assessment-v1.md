# Relational-State Directional Assessment v1

Status: **FROZEN BEFORE COMPONENT-PLACEMENT TRAIN OUTCOME**  
Date: **2026-09-19**  
Parent experiment: **Component-Placement Junction Law Test v1**

## Directional claim

The project's default model should no longer be:

> A component has an intrinsic state, and degree, placement, neighborhood and history are contextual features that improve prediction of its consequence.

The better-supported directional model is:

> **The relevant state is relational. A component's role inside a larger organized whole is part of the identity of the state itself.**

Under this model, many apparent exceptions are expected to arise when distinct relational states are projected onto the same lower-dimensional label.

The basic ontology candidate is therefore not an isolated object, center, junction, glyph or component.

It is a **component-in-role**.

## Why the existing Mark evidence supports this move

### 1. Source-local recurrence is already too strong to treat the law as a loose aggregate tendency

Across the 705 untouched sources in the strict law census:

- junction condition: 610 strict matches / 8 strict reversals / 85 unresolved among 703 eligible sources;
- endpoint condition: 634 strict matches / 3 strict reversals / 64 unresolved among 701 eligible sources;
- 607 sources strictly match in both directions.

The broad law is therefore not being created merely by pooling unrelated sources.

### 2. Whole-source density failed as the branch selector

The preregistered pair-density hypothesis failed in the opposite direction from the prediction.

This rules out the simple model in which a coarse whole-object scalar causes the matching law to weaken or reverse.

### 3. Degree is a real state coordinate, but not a sufficient one

The degree-conditioned experiment produced:

- 33 train-admitted matching candidates;
- 20 holdout passes;
- 18 train -> holdout -> control survivors.

So degree is not arbitrary noise: conditioning on it exposes reproducible sublaws.

But degree alone is falsified because identical degree + arm cells still contain both STRICT_MATCH and STRICT_REVERSE states across independent sources in train, holdout and control.

This is consistent with a projection problem:

```
multiple distinct relational states
        ↓ projected onto
same degree/arm label
        ↓
apparent contradiction
```

### 4. Five independent Mark constraints already establish that component inventory is not state identity

Law-Equivalence Adjudication cluster EQC-001 contains five independent Mark constraints:

- MCR-016
- MCR-034
- MCR-083
- MCR-087
- MCR-007

They pass the strict same-law criterion against CIR-018 under the neutral law:

> **Component inventory cannot substitute for relational placement/order.**

The decisive contrast repeated across those experiments is:

```
preserve constituents / identities
change relation or order
        ↓
organized consequence / function changes
```

The stronger interpretation is not merely that relation is a useful predictor.

It is that a representation which calls the state "the same" after destroying the relevant relation is an incomplete state representation.

### 5. The prior masked-slot experiment points from static identity toward role

The independently frozen masked-slot instrument removes the target topology from its context and defines its structural slot from the containing observation, relative geometry and sibling organization.

Its transfer result was not strongest for static context similarity. The more stable signal was preservation of downstream child-program behavior among discovered substitution families.

That result is directionally consistent with:

> **operational role can transfer more strongly than intrinsic physical identity or static snapshot similarity.**

It does not prove that role is sufficient. It does argue against treating intrinsic form as the complete state.

## External research that licenses the stronger interpretation

This assessment does not use outside research as evidence for the Mark result. It uses outside research to determine whether the stronger interpretation is scientifically coherent enough to state directionally.

### Spatial biology

Recent spatial-omics work separates intrinsic cellular state from spatially induced state and treats neighborhood organization as part of the state needed to explain behavior rather than as nuisance metadata.

Related work on persistent local tissue relationships shows that local relational organization can carry predictive signal not captured by composition alone.

Work on conditional spatial relationships also shows that global or symmetric summaries can collapse directionally different organizations into apparently similar states.

### Robotics / causal world models

Influence-neighborhood approaches search for the smallest surrounding relational subset required to predict a masked object's state.

That provides a close formal analogue to the problem now exposed in Mark:

> find the **minimum sufficient relational neighborhood** under which apparent ambiguity disappears.

### Materials / many-body modeling

Modern interatomic models do not treat atomic identity as a sufficient state description. Predictive state is built from the atom plus its local many-body environment, while known invariances are encoded rather than repeatedly relearned.

This is compatible with the same representational move without implying law identity across substrates.

## Stronger working model

The current research direction is therefore:

```
intrinsic configuration
+ relation to containing whole
+ directional relation to neighbors
+ structural role
+ relevant prior relational history
        =
candidate complete state

candidate complete state
        ↓
constrained consequence
```

This is a directional model, not a completed proof.

## What the current component-placement experiment now tests

The Component-Placement Junction Law Test v1 should not be interpreted as:

> Is placement the answer?

It tests:

> Does the already-frozen masked structural-slot coordinate recover enough of the missing relational state to separate law branches that degree could not separate?

If it succeeds strongly, relational role becomes substantially more concrete.

If it succeeds only partially, the next search should remain inside the relational-state hierarchy rather than returning to arbitrary feature hunting:

1. component placement;
2. directional neighborhood;
3. sibling/parent role;
4. relevant prior relational state/history;
5. minimal sufficient influence neighborhood.

## Falsification boundary

This directional claim remains vulnerable.

If increasingly complete relational-state descriptions fail to reduce the strict contradictions, or if non-relational intrinsic variables explain them more cleanly under held-out transfer, the model must be revised.

The claim is therefore:

> **The best-supported current direction is to reconstruct the minimum relational state representation under which consequence becomes invariant.**

It is not yet:

> every contradiction is a projection artifact,

nor:

> one universal relational law has been proven.
