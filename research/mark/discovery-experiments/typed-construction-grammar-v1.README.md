# Typed construction grammar v1

This branch performs a retrospective architecture synthesis over already-frozen Mark experiment artifacts. It does not re-open source pixels, refit source analyses, or claim that the contributing experiment lineages are independent replications.

The synthesis asks whether accumulated results are more coherent as a typed construction grammar than as a flat inventory of equally meaningful shape features. The frozen types are edge scaffold, junction/vertex, boundary/cycle, relation, degree, state/program, residual realization geometry, and style realization.

Scientific outcomes are allowed to fail without failing CI. The workflow fails only for artifact custody drift, missing inputs, or analysis errors.
