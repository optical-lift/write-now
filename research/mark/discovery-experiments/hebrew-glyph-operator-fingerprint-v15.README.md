# Hebrew ↔ Glyph Operator Fingerprint v15

V15 is the first deliberately cross-corpus experiment between the Hebrew MT token stream and the frozen Linear A glyph sequence packet.

It does **not** compare visual forms, inherited meanings, translations, phonetics, or Strong's definitions. Both corpora are projected through the same alphabet-free structural machine: the incoming state is only the equality pattern of the previous four operator identities, and the consequence is only the next item's repetition/newness/end relation to the current and recent history.

For each operator, the experiment estimates its residual consequence law relative to that corpus's state baseline. Hebrew and glyph fingerprints therefore live in the same anonymous state/outcome coordinate system even though their symbol inventories are unrelated.

Train-only mutual-nearest Hebrew↔glyph pairs are frozen before either evaluation lane is downloaded. The pair survives only if its similarity is unusually high again in both reused evaluation lanes against ordinary and support-stratified permutation controls.

A positive result would establish cross-corpus stability of a narrow structural operator fingerprint. It would not establish a translation, historical contact, common origin, divine authorship, phonetic reading, or executable machine.
