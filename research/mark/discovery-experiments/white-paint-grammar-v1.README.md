# Mark white-paint grammar v1

This experiment calibrates a proposed pre-semantic glyph grammar before any historical-semantic claim is attempted.

The working model is:

`OPERATION × RELATION × DEGREE`, with `CLOSURE` treated as a topology phase operator.

The synthetic lane is deliberately a known system: the generator knows the intended structural class, while the extractor sees only anonymous graph nodes, edges, and geometry. The primary purpose is to establish that Mark can recover the proposed axes under style changes and nuisance modifier forms before those axes are tested against unknown historical witnesses.

The physical screen uses only the already-frozen v5 critical-edge graph observations. It measures whether junctions, parallel path multiplicity, critical-graph cycles, and path turning are present often enough to justify a later blind historical test. It does not use provenance, role labels, States 1–3, transition grammar, cultural labels, or semantics.

Passing v1 means the proposed grammar is technically recoverable in a controlled system and observable in physical graph evidence. It does **not** mean the grammar is universal, historical meanings have been decoded, or any Atlas label has been discovered in ancient marks.

The next experiment, if v1 passes, should freeze witness selection, axis definitions, scoring rules, null worlds, and transfer lanes before opening historical context.
