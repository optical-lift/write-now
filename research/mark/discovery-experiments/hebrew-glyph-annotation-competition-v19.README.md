# Hebrew ↔ glyph annotation competition v19

V19 treats Song, conventional linguistics, and blind Hebrew structure as competing annotation systems rather than an authority hierarchy.

The Song map is frozen from explicit Strong's starter-ID groupings already present in `Song Control Map v2` and `Song_Control_Registry_v1`, both authored before the current glyph experiments. OSHB morphology is a competitor, not ground truth. The blind map is induced from Hebrew train fingerprints with no human labels.

All three maps are forced onto the same Song-covered Hebrew panel and the same label-blind, train-frozen one-to-one glyph pairing. The evaluation target is glyph-to-glyph behavioral organization, which no annotation system defines for itself.

Because holdout/control were opened in prior experiments, V19 is a frozen diagnostic comparison, not fresh independent confirmation.
