# Hierarchical Graph Compression v8

This experiment is intentionally stacked on local wiring motif correspondence v7 for scientific lineage, but it does not consume the V7 artifact or its radius-2 motif vocabulary.

The only data input is the frozen V5 critical-edge packet. V8 first removes preserved/broken role labels from the available evidence path, induces both a terminal-only flat dictionary and a recursive lossless edge-bundle contraction grammar from Cleveland/train graphs, and seals those grammar packets. Only after the grammar freeze is hashed are the role labels restored for correspondence scoring.

The primary representation uses the same primitive length-aware edge encoding that was the only V7 primary to clear the Cleveland discovery gate and transfer to Bavaria. Topology-only is frozen as an ablation. This does not presume that length is causal.

The recursive grammar has no radius boundary. A production may recursively contain previously learned nonterminals as long as it lowers the predeclared structural description code, is supported across at least three source groups, appears at least six non-overlapping times, and remains within the frozen rule/depth limits.

The claim gate is deliberately two-part: recursive grammar must beat the flat dictionary in held-out Bavaria compression, and frozen rule-ancestry paths at blindly mapped centers must be more conserved in preserved-role observation pairs than broken-role controls in Cleveland and Bavaria. Either half can fail independently.
