# Hebrew ↔ Glyph Ablation Ladder v17

V17 is a diagnostic follow-up to V15 and V16. V15 found transferable Hebrew↔glyph matches in an anonymous repetition/state-transition fingerprint space. V16 showed that the correspondence did not survive a bundle of stronger controls. V17 asks which control is responsible.

The experiment freezes ten variants from train only:

- one V15-like baseline under uniform V17 fitting/gating rules;
- five isolated controls: boundary removal, segment-length/contribution control, seen/new collapse, proper-name exclusion, and frequency matching;
- four additional cumulative rungs ending in the full five-control configuration.

Every variant independently freezes its shared states, candidate operators, train-only mutual-nearest pair panel, and frequency strata before either evaluation lane is downloaded.

The localization rule is predeclared. The baseline must first pass the same V17 gates. If it does not, V17 makes no attribution. If it passes, an isolated control is sufficient to break the V15-style adjudication only when that isolated variant fails. The cumulative first break is the first failing rung after the passing baseline/previous rung. Failures are classified separately as train-feasibility collapse, evaluation-support collapse, or transfer-gate failure.

V17 is not a semantic-decoding experiment and not fresh independent confirmation: the evaluation lanes were already opened in earlier experiments. Its purpose is to determine which structural ingredients the V15 correspondence actually depends on.
