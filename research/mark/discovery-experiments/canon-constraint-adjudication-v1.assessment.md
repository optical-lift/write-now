## The most important result

The 14 direct Mark↔canon matches collapse onto only **7 canon rules**.

### CIR-001 — Condition governs permitted operation

Blind direct Mark matches:

- `MCR-069`
- `MCR-072`
- `MCR-028`

Canon rule:

> the same participant/body does not have the same permitted operation under every governing state; context changes operation.

Mark independently found:

- context changes consequence;
- context plus active participant changes immediate consequence;
- a local relation configuration changes consequence distribution.

This is the clearest convergence on **condition-specific consequence**.

### CIR-002 — Actor/jurisdiction is additional condition information

Blind direct Mark matches:

- `MCR-059`
- `MCR-089`
- `MCR-060`

Canon rule:

> state/position alone is insufficient; actor assignment/jurisdiction matters.

Mark independently found three versions of:

> **state alone cannot determine consequence; the active participant matters.**

One of these comes from counterfactual substitution with incoming state held fixed.

This is particularly strong because the three Mark experiments reached the same canon rule through different measurement designs.

### CIR-018 — Ordered arrangement cannot be reduced to component inventory

Blind direct Mark matches:

- `MCR-083`
- `MCR-087`
- `MCR-007`

Canon rule:

> keeping the parts but discarding their ordered physical arrangement loses the described operation structure.

Mark independently found:

- spatial-topology destruction collapses recurrence;
- early cross-source recurrence exceeds topology-destroying nulls;
- reversing/shuffling the same sequence members destroys hidden-path information.

This is a direct cross-substrate convergence on:

> **the things present are not sufficient; how they are ordered/related is part of the condition.**

### CIR-017 — Ordered history/composition determines later state

Blind direct Mark matches:

- `MCR-020`
- `MCR-056`

Canon rule:

> the same referent can pass through an ordered operation-chain, and later condition depends on the accumulated sequence rather than a single isolated operation.

Mark independently recovered factorized sequential composition in two different experiment generations.

### CIR-003 — Changed history changes lawful continuation

Blind direct Mark match:

- `MCR-042`

Canon rule:

> prior authorization does not automatically determine what follows after a new outcome; recent history changes the continuation condition.

Mark independently found second-order state memory: current state alone loses information contained in recent history.

### CIR-006 — Counted/ordered prior history generates later state

Blind direct Mark match:

- `MCR-036`

Canon rule:

> later state is generated through ordered prior history rather than present coordinate alone.

Mark independently found nonrandom transitions and short state programs.

### CIR-020 — Relative timing changes consequence

Blind direct Mark match:

- `MCR-078`

Canon rule:

> the same participant/relation can have different legal consequence depending on relative timing within a defined window.

Mark independently found a reproducible proximal structural footprint around a masked active position.

The surface systems are very different. The dependency structure is not.

## Partial matches

Nine packets found related canon structure but not enough for a direct adjudication.

Important partials include:

- `MCR-029` and `MCR-031` → `CIR-009`: Mark statistical exclusion resembles canon state-specific prohibition, but suppression below null cannot be upgraded to absolute/normative prohibition.
- `MCR-022` and `MCR-057` → `CIR-015`: Mark cancellation/return resembles canon restoration of prior fitness, but canon does not independently establish the same A→B cancellation algebra or repetition idempotence.
- `MCR-016` and `MCR-034` → `CIR-007/CIR-018`: placement/order matters in both systems, but the exact predictive-null structure differs.
- `MCR-037` → `CIR-016`: Mark commitment/return asymmetry resembles directional movement toward stabilized planted dwelling, but canon does not establish a general hysteresis law.

These should remain partial.

## Five genuine no-matches

The frozen canon inventory did **not** supply a sufficient rule for:

1. `MCR-052` — selective recurring connection-edit constraints;
2. `MCR-051` — recurring junction-edit constraints beyond gross shape;
3. `MCR-015` — hidden-center information recoverable from surrounding relations;
4. `MCR-050` — transferable relational-arrangement edit atoms;
5. `MCR-021` — repetition idempotence: repeating the same operation leaves its consequence kernel invariant.

These are now high-value canon research targets.

They must not be backfilled into v1.

Any new canon discovery for them belongs to a subsequent, explicitly post-hoc targeted canon search.

## What this proves

This checkpoint proves a narrower but important proposition:

> **When 28 Mark constraints are anonymized and compared only after a canon-only rule inventory is frozen, 14 independently recover substantially the same condition/consequence structure already present in Noel's canon evidence, and another 9 recover partial structural correspondences.**

It also proves that the convergence is concentrated.

The direct matches are not spread across 14 unrelated canon ideas. They repeatedly land on:

- condition-governed consequence;
- actor/jurisdiction beyond state;
- order/arrangement beyond inventory;
- ordered history/composition;
- history-sensitive continuation;
- generated state through prior sequence;
- relative timing.

## What this does not prove

It does not yet prove:

- that Mark and canon instantiate literally the same universal laws;
- that the canon exhaustively describes all physical constraints;
- that the 7 canon rules are fundamental/irreducible;
- that direct structural matches are causally or historically related;
- that the five no-matches are absent from canon;
- that statistical exclusion equals normative prohibition.

Those are later questions.

## Why this matters for the user's hypothesis

The strongest convergence is exactly where the user redirected the project:

> **condition + relation + order → constrained consequence**

The blind comparison did not primarily converge on nouns, symbols, meanings, or fixed operator names.

It converged on the fact that:

- state alone is insufficient;
- participant alone is insufficient;
- inventory alone is insufficient;
- order cannot be discarded;
- placement cannot be discarded;
- history cannot be discarded;
- consequence changes when the complete relation changes.

That architecture had already been discovered independently on both sides.
