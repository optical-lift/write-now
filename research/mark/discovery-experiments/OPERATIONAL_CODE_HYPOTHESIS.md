# Operational code hypothesis

This note records the claim being tested beside the Mark machinery rather than leaving it implicit in discussion.

## Claim

**These marks behave like code.**

The claim is operational, not metaphorical: a finite repertoire of structural units may constrain state transitions; the same units may recur; their effects may compose; and repeated use may permit the underlying transformation rules to be inferred before conventional sign meanings are supplied.

The stronger working sentences are:

- **The glyph is not merely carrying information. Its construction may participate in specifying an operation.**
- **The system can be approached as an instruction system before it is approached as a language.**
- **An inscription may be not only a sequence of things to be read, but a sequence of transformations applied over a state.**
- **If the same glyph repeatedly takes equivalent incoming states to equivalent outgoing states across independent inscriptions, then part of its function has been recovered without translation.**
- **If a finite set of glyph operations predicts the structure of inscriptions it has never seen, then the corpus is behaving like a program generated by a grammar rather than an arbitrary collection of symbols.**
- **The practical objective is to recover a compact machine that can run the rules forward and predict what comes next. If that succeeds under held-out evaluation, we have recovered part of the code the makers were using.**

A useful machine target is:

```text
alphabet of operators
+ state space
+ admissible compositions
+ boundary conditions
+ invariants
= executable grammar
```

## V9 correction

V9 remains evidence that the Mark representation can recover compositional graph behavior, but it is not accepted here as a historical decoder. The topology-only transition behavior is heavily constrained by ordinary graph bookkeeping: once center degree, incoming-port multiplicity, side branches, and self-loop budget are known, much of the outgoing multiplicity is forced. That layer is instrumentation/plumbing, not yet the instruction set.

Therefore the next experiment asks for the **residual consequence of glyph identity after subtracting generic sequence context and structural boundary effects**.

## Current falsifiable form

For a recurring glyph `g`, define an incoming anonymous sequence state `s_in` and a following anonymous sequence state `s_out` without consuming transliteration, translation, provenance, or proposed meaning.

A code-bearing operator must satisfy all of the following under an untouched inscription holdout:

1. `P(s_out | s_in, g)` predicts better than `P(s_out | s_in)`.
2. The gain is not confined to one inscription.
3. Glyphs with similar learned transition kernels can be compressed into a finite functional class inventory without losing most of the held-out predictive gain.
4. The class inventory is frozen before any conventional reading is reopened.
5. A claimed function is the empirically recovered transition behavior. A historical gloss is a separate rejoin step.

Failure is informative. If glyph identity contributes no transferable residual after context and boundaries are accounted for, this representation does not recover operational code.

## What this work is trying to compute

The target is not an infinite catalog of readings. It is a finite transition table:

```text
operator × incoming state -> outgoing-state distribution
```

followed by a finite quotient of operators into action-equivalent classes. The scientific question is whether that finite machine predicts unseen inscriptions.
