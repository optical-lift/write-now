After confirmation, six centroid-near validation/confirmation samples were inspected for each regime, deliberately drawing from BSB, Library of Congress, and Cleveland where available.

### RG-001

Representative samples include:

- dense engraved/illustrated linework;
- hatching and branched drawing structure;
- complex scene fragments;
- textured image regions.

The common visual property is not a shared subject. It is comparatively branched, junction-rich, cycle-rich local structure.

### RG-002

Representative samples include:

- binding/edge texture;
- photographic object fragments;
- painted decorative fragments;
- drawing fragments.

It is a broad intermediate regime containing mixed but less extremely branched structure than RG-001 and less long-path-dominated structure than RG-004/005.

### RG-003

Representative samples include:

- isolated small printed/drawn marks;
- broken architectural/photo fragments;
- sparse decorative fragments;
- disconnected texture pieces.

This agrees with the blind signature: high component/endpoint density and comparatively fragmented structure.

### RG-004

Representative samples include:

- printed text;
- typography fragments;
- long smooth object contours;
- simple continuous curved/linear edges.

This agrees with the blind signature: strong degree-2 path structure and longer paths with fewer junctions.

### RG-005

Representative samples include:

- isolated long letter strokes;
- a handwritten/printed letter-like loop;
- a long rule/text-line fragment;
- smooth isolated vessel/object contours.

The regime is not “letters.” It is an extreme long-path / concentrated-topology regime that letters can instantiate alongside non-symbolic contours.

## Interpretation

The context audit argues against treating any one RG regime as a semantic or writing category.

Instead, the regimes look like reusable **structural modes**:

- highly branched/complex;
- intermediate mixed;
- fragmented/endpoint-heavy;
- long continuous path;
- extreme long/concentrated path.

These modes recur across semantically unrelated material.

The important new observation is therefore not “which regime means writing?”

It is:

> The same source object contains multiple recurring structural modes at different proposal scales, and the distribution of those modes changes systematically across real media.

That makes **regime transition across scale** a stronger next target than regime identity alone.
