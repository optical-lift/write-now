# Mark Universal Observable Engine v2

Mark v2 does not begin with alphabets, languages, cultures, or object classes. It begins with **observable configurations**.

The governing experiment is the ten-boxes problem: dump pieces from many supposedly separate puzzles onto one floor, remove the box art, preserve custody separately, and ask what recurrent structures and transformations actually organize the combined field.

## Constitutional rule

Source category is context, not input.

The blind discovery process may know only what is technically necessary to measure an observation:

- opaque observation ID
- opaque independent-source ID
- capture adapter
- local capture bytes
- region/crop
- segmentation instructions
- source-level train/holdout lane

It may not know object category, culture, language, sign name, reading, meaning, chronology, geography, institution, catalog identity, or scholarly interpretation.

Those fields remain in a separate custody/rejoin artifact and can be reopened only after the blind world is SHA-256 sealed.

## One field, not ten boxes

The image adapter deliberately accepts any 2D capture without asking whether it is a glyph. A photographed letter, knot, bead string, textile motif, seal, game-board mark, map mark, ritual diagram, mathematical sign, architectural scratch, or interface symbol enters through the same contract.

Future adapters can emit the same canonical observable record from sequence, graph-native, 3D, or other capture forms. The world model is adapter-independent once measurement is complete.

## Pipeline

1. **Custody preparation**
   - exact source bytes are hashed outside the blind process;
   - source and observation identities are replaced with salted opaque handles;
   - physical-evidence packets cannot author-select holdout sources;
   - identical physical capture bytes cannot count as independent source objects;
   - contextual metadata is written to a separate rejoin artifact.

2. **Observable measurement**
   - current `image_2d` adapter measures topology, geometry, symmetry, density, component distribution, repetition, boundary complexity, and position;
   - the output is a common structural record, not a character record;
   - synthetic fixtures are permanently marked non-evidence.

3. **Source-level holdout**
   - physical corpora receive a deterministic source-object split before discovery;
   - the learner receives a train-only sealed feature file;
   - the holdout file is a separate sealed artifact.

4. **Blind world learning**
   - build a nearest-neighbor graph over the mixed field;
   - discover structural communities without category labels;
   - discover recurrent primitive states across independent source objects;
   - discover recurrent transformations from quantized feature deltas between cross-source neighbors;
   - seal the learned world before opening the holdout.

5. **Blind prediction**
   - map unseen holdout observations to frozen structural families;
   - rank unseen cross-source pairs against frozen operations;
   - seal prediction results.

6. **Full-world assembly**
   - only after prediction is sealed, add the holdout measurements back into the blind field;
   - rebuild the complete structural world using every observable configuration;
   - seal it again.

7. **Context rejoin**
   - reopen the old box labels only after the full world is frozen;
   - report how many machine families, primitive states, and operations cross those prior categories;
   - category mixing is an observation about the frozen graph, never a discovery input.

## What a world edge means

Similarity is only one edge type. The model also learns recurrent transformation vocabulary. An operation is a repeated structural delta such as a change in enclosure, component count, branch/junction structure, terminal structure, symmetry, orientation, aspect, density, repetition, or boundary complexity.

The engine does not name those operations `JOIN`, `ENCLOSE`, `REPEAT`, etc. Those are possible human descriptions after freeze. Blind artifacts carry only machine signatures and opaque operation IDs.

## What this does not assume

A recurrent structure does not prove a single historical origin. The same structural grammar can be compatible with inheritance, diffusion, convergence, material constraints, motor constraints, cognitive economy, or a mechanism not yet considered.

Mark's job is earlier than that argument: establish what the recurring machinery actually is before deciding why it recurs.

## Ten-box fixture

CI includes a synthetic corpus with ten hidden contextual boxes: script, knot, beadwork, map, textile, seal, game, astronomical, mathematical, and interface. The blind pipeline cannot see those labels.

The fixture exists only to prove architectural behavior: context stripping, source independence, mixed-field learning, source-level holdout, frozen prediction, full-world assembly, and post-freeze cross-box rejoin. It can never be promoted as historical evidence.

## Real corpus direction

The next corpus should not be a hand-picked pair test. It should be a broad intake queue of governed physical observations. Human work belongs in custody and capture quality: locate objects, preserve exact bytes, record provenance, and define observable regions. Once admitted, all observations enter the same blind field.
